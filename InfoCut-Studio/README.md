# InfoCut Studio

정보 전달용 쇼츠와 롱폼을 만드는 프로그램. 주제를 정하면 AI 가 자료를 찾아 대본을 쓰고, 표·그래프·자막이 들어간 영상으로 만든다. 장면 하나하나 고치거나 프리미어 프로로 넘겨 마무리할 수 있다.

두 가지로 쓴다. 같은 프로젝트를 `.infocut` 파일로 주고받는다.

- **PC 버전**: 조사, 대본, 편집, 렌더, 프리미어 프로 내보내기
- **휴대폰 버전 (안드로이드 APK)**: PC 없이 휴대폰 혼자 조사부터 MP4 저장까지

## PC 버전

처음 한 번

1. **Node.js**, **Python** (무료 목소리용, Microsoft Store 의 Python 3.12 이상)
2. `설치.bat` 더블클릭 (2~5분)
3. `프리미어패널_설치.bat` 더블클릭 후 프리미어 다시 켜기 (패널을 쓸 때만)

매번 `InfoCut 시작.bat` 을 실행하면 브라우저에 편집 화면이 열린다. 검은 창은 켜 둔다.
처음 [영상 만들기]를 누르면 렌더링용 브라우저(약 100MB)를 한 번 내려받는다.

화면 구성: 왼쪽 장면 목록, 가운데 미리보기와 타임라인, 오른쪽 패널(장면 / 조사 / 디자인 / 소리 / 내보내기).

## 휴대폰 버전

APK 받는 법 (둘 중 하나)

- GitHub 저장소의 **Actions > InfoCut APK** 에서 가장 최근 실행을 열고 아래쪽 **InfoCut-apk** 를 내려받는다. 압축을 풀면 `InfoCut.apk` 가 나온다
- PC 에서 `APK빌드.bat` 더블클릭. JDK 와 Android 도구를 `data\android-tools` 에 자동으로 받고(처음 한 번, 약 1.5GB) `InfoCut.apk` 를 만든다

휴대폰에서 APK 를 열어 설치한다 ("출처를 알 수 없는 앱" 허용 필요). 새 APK 로 덮어 설치해도 프로젝트는 남는다.

- 화면: 위 미리보기, 아래 탭(조사 / 편집 / 디자인 / 소리 / 내보내기). 장면을 누르면 편집 시트가 올라온다
- 저장: 프로젝트, 사진, 소리, 키 전부 휴대폰 안에만 저장된다. 앱을 지우면 같이 지워진다
- 목소리: 휴대폰 기본 목소리(무료, 설정 > 글자 읽어주기의 한국어 음성), OpenAI, ElevenLabs
- 렌더: 휴대폰 안에서 MP4 를 만들어 갤러리(Movies/InfoCut)에 저장한다. 만드는 동안 앱을 켜 둔다
- 프리미어 내보내기는 PC 에서만 된다. [내보내기 > PC 로 보내기]로 `.infocut` 파일을 만들어 PC 로 옮긴 뒤 PC 버전 [가져오기]로 연다. "자막 포함"을 끄고 만든 MP4 를 프리미어에 바로 올려도 된다

## 만드는 순서

| 단계 | 하는 일 |
|---|---|
| 조사 | 주제, 방향, 참고 링크를 적으면 AI 가 웹에서 사실, 숫자, 출처를 모으고 영상 방향 3개를 제안한다. 쓸 사실만 체크하고 방향을 고른 뒤 [대본 쓰기] |
| 장면(편집) | 장면마다 문장(=자막)과 화면 종류를 고친다. `/` 는 자막 끊는 자리. 아래 "AI 수정"에 "더 짧게", "표로 바꾸기"처럼 적으면 그 장면 또는 대본 전체를 고친다 |
| 디자인 | 화이트 / 블랙 / 풀화면, 강조색, 쇼츠 위쪽 제목, 자막 크기와 모양, 출처 표시, 컷/페이드, 내 캐릭터 PNG |
| 소리 | 나레이션 엔진, 목소리, 빠르기, [목소리 만들기]. 효과음 역할별 파일, 배경음악 |
| 내보내기 | 완성 MP4, 프리미어용 XML(PC), `.infocut` 파일, 유튜브 글 복사, 기록 되돌리기 |

화면 종류 11가지: 제목, 사진·영상, 숫자, 막대 그래프, 표, 인용, 목록, 비교, 타임라인, 글, 장 표지

대본은 사람이 쓴 것처럼 들리게 쓰도록 규칙을 넣어 두었다 (`src/shared/ai/writer.ts` 의 WRITING_RULES). 진행 멘트, 꾸밈말, 셋씩 나열, 교훈으로 끝내기를 금지한다. 채널 말투에 맞게 이 규칙을 직접 고쳐도 된다.

## 프리미어로 넘기기

[프리미어용으로 내보내기] → `data\projects\<프로젝트>\exports\premiere\`

- `…_프리미어.xml` — 프리미어 [파일 > 가져오기] 또는 InfoCut Bridge 패널 [XML 고르기 → 가져와서 열기]
- 트랙: V1 배경 / V2 장면 화면(투명 ProRes 4444, 장면마다 잘림) / V3 자막(한 줄 = PNG 한 장) / V4 비어 있음(MOGRT 자리) / A1 나레이션 / A2 효과음 / A3 배경음악 / 장면·장 마커
- 패널 [자막 적용]: 고른 .mogrt 를 자막마다 V4 에 올리고 글자를 채운 뒤 V3 을 숨긴다
- `자막.srt`, `media\원본_사진영상\`, `프리미어에서_여는_법.txt`

## 설정

- AI: Claude / Gemini / GPT 중 하나 고르고 키 넣기. [목록]으로 모델 선택(비우면 자동). 키는 PC 는 `data\settings.json`, 휴대폰은 앱 안에만 저장
- 사진 검색: 위키미디어 공용(키 없음, 상업 이용 가능한 라이선스만), Pexels·Pixabay(무료 키)
- 내 에셋: 효과음·배경음악·MOGRT·사진 폴더 등록. 프리미어 MOGRT 폴더와 다운로드의 "효과음 120가지" 폴더는 처음부터 들어가 있음

## 폴더

```
server/          PC 서버 (목소리 voice.ts, 에셋 assets.ts, 렌더 render.ts, 프리미어 premiere.ts)
src/shared/      PC 와 휴대폰이 같이 쓰는 코드: 프로젝트 구조, 장면 시간 계산, .infocut 묶음(pack.ts)
src/shared/ai/   AI 연결(llm.ts), 조사·대본(writer.ts), 사진 검색(media.ts)
src/video/       영상 디자인 (Remotion): theme.ts 색·배치, Visuals.tsx 장면 11종, Video.tsx 자막·출처·소리
ui/              편집 화면 (React). PC 와 휴대폰이 같은 코드를 쓴다
ui/src/local/    휴대폰 단독 엔진: 저장(IndexedDB), 목소리, 렌더(WebCodecs), 서버 대신 요청을 처리하는 router.ts
android/         안드로이드 앱 (Capacitor). InfoCutPlugin.java 가 기본 목소리, 갤러리 저장, 공유를 맡는다
cep/             프리미어 패널 InfoCut Bridge
assets/sfx/      내장 효과음
data/            PC 프로젝트와 설정 (지우면 다 사라짐)
```

개발용 명령: `npm run build:ui` (PC 화면), `npm run build:mobile` (휴대폰 화면, `mobile/www`), `npx cap sync android`, `npm run typecheck`

## 알아 둘 것

- 대본의 숫자·인용은 AI 가 찾은 자료 기준이다. 올리기 전에 탐구 노트의 출처 링크로 한 번 확인할 것
- 받은 효과음·음악·사진은 상업 이용이 되는지 확인할 것 (위키미디어, Pexels, Pixabay 출처는 [출처 붙이기]로 설명란에 넣을 수 있음)
- Remotion 은 개인·3명 이하 팀은 무료 (회사 규모가 커지면 라이선스 필요)
- 프리미어 XML 은 OpenTimelineIO 로 구조를 검증했지만 프리미어에서 직접 열어 보지는 못했다. 패널의 MOGRT 적용도 실제 프리미어에서는 처음 실행해 보는 것이니 문제가 있으면 알려 줄 것
- 휴대폰 버전은 브라우저 화면 크기에서 조사 화면, 편집, 렌더(1080×1920 MP4)까지 확인했다. 실제 안드로이드 기기에서는 처음 실행해 보는 것이라 기본 목소리, 갤러리 저장, 공유에 문제가 있으면 알려 줄 것
- 휴대폰 렌더는 기기가 H.264 인코딩을 못 하면 WebM 으로 만든다. 긴 롱폼은 휴대폰 메모리가 모자랄 수 있으니 PC 에서 렌더하는 편이 안전하다
