# InfoCut Studio 설계 근거

## 1. 벤치마킹한 채널 (2026-11-12, Chrome 으로 직접 확인)

### 저세상개발자 (구독 10.1만, 게임 개발·기술 설명)
- 화면을 꽉 채우는 실제 게임 화면·3D 렌더 위에 설명을 얹는 방식
- 자막: 화면 아래 가운데, 굵은 흰 글자에 어두운 외곽선
- 왼쪽 위에 지금 보이는 게임 이름을 작게 표시 (출처 역할)
- 채널 캐릭터가 화면 구석에 가끔 등장
- 컷 전환 위주, 효과는 거의 없음

### 제스처 (구독 5.11만, 버튜버 분석)
- 연한 배경에 모눈 무늬, 그 위에 흰 판(카드)
- 표·순위표·막대 그래프·기사 인용 카드로 숫자를 직접 보여 줌
- 강조는 한 가지 색(파랑)만, 강조 행은 테두리로
- 오른쪽 위에 "출처 : ○○" 를 작게 표시, 자막은 작은 반투명 박스
- 쇼츠: 위쪽 두 줄 제목 + 가운데 화면 + 아래 자막

### 공통점 → InfoCut 원칙
정보가 주인공 / 출처를 화면에 밝힘 / 강조색은 하나 / 전환·효과는 최소 / 숫자는 그래프와 표로.

### 표절이 되지 않게 바꾼 점
| 요소 | 채널 | InfoCut |
|---|---|---|
| 배경 무늬 | 선 모눈 + 파스텔 그라데이션 | 점 무늬(노트), 짙은 남색 모눈(잉크), 무늬 없음(필드) |
| 기본 강조색 | 밝은 파랑 | 코발트·호박·하늘 등 고르는 색 |
| 출처 표시 | 오른쪽 위 검은 알약 | 판 아래 글자(그래프), 사진 위에만 박스 |
| 자막 | 반투명 박스 / 외곽선 | 흰 박스+테두리(노트), 남색 박스(잉크), 외곽선(필드) |
| 장 표지 | 없음 | "N장" + 짧은 강조선 |
| 글꼴·배치 | 채널 고유 | Pretendard, 왼쪽 정렬 위주, 자체 격자 |

## 2. 전문가들이 쓰는 도구 → 그대로 채택

| 하는 일 | 전문가 도구 | InfoCut 에서 |
|---|---|---|
| 영상 그리기 | **Remotion** (React 로 영상을 코드로 만드는 프레임워크, 자동 영상 제작의 표준) | 장면 11종을 Remotion 컴포넌트로. 편집 화면 미리보기도 같은 코드(Remotion Player) |
| 인코딩 | FFmpeg (Remotion 에 내장) | H.264 완성본, ProRes 4444 투명 레이어 |
| 대본·조사 | LLM + 웹 검색 (Claude·Gemini·GPT) | 세 회사 모두 연결, 각 회사의 웹 검색 도구로 근거 수집 |
| 나레이션 | edge-tts / OpenAI TTS / ElevenLabs | 셋 다 지원, 단어별 시간으로 자막 맞춤 |
| 편집 교환 | **Final Cut Pro 7 XML** (프리미어가 읽는 표준), OpenTimelineIO 로 검증 | 트랙 분리 XML + SRT, OTIO 로 구조 검증 |
| 프리미어 자동화 | **CEP 패널 + ExtendScript** (MOGRT 글자 조절은 아직 UXP 로 안 됨, Adobe 는 CEP 지원 종료 계획 없다고 밝힘) | InfoCut Bridge 패널: XML 가져오기, MOGRT 자막 일괄 적용 |

## 3. 내 컴퓨터에서 찾은 에셋 (자동 등록)
- 프리미어 프로 2025, 애프터 이펙트 2025 설치됨
- `AppData\Roaming\Adobe\Common\Motion Graphics Templates`: 기본 자막 템플릿(Simple/Modern/Bold/Classic/Film Web Caption 등), 하단 자막, 타이틀, 구독 버튼, 포켓몬 몬스터볼 자막바 등
- `다운로드\효과음 120가지 #01, #02`: 정보 영상에 맞는 잔잔한 소리(넘기는 소리, 띠링, 찰칵, 키보드)는 자동 추천, 큰 소리·밈 소리는 추천에서 뺌
- InfoCut 내장 효과음 4개 (코드로 합성, 저작권 걱정 없음)
