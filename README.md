# 말랑 면접 — AI 면접 훈련기

말로 답하면 면접관 마스코트 **말랑이**가 듣고, 꼬리질문을 던지고, 채점해 주는 면접 연습 프로그램입니다.
설치 없이 브라우저(크롬/엣지)에서 바로 돌아가며, 무료 Gemini API 키만 있으면 AI 면접관까지 쓸 수 있습니다.

## 실행 방법

```bash
# 이 폴더에서
python3 -m http.server 8000      # 또는: npm start
```

그다음 크롬에서 <http://localhost:8000> 을 엽니다.
(`index.html`을 더블클릭해서 열어도 동작하지만, 그러면 마이크 권한을 매번 물어봅니다.)

> 음성 인식은 **크롬 또는 엣지**에서만 됩니다. 사파리/파이어폭스에서는 타이핑 모드로만 진행됩니다.
> 크롬 음성 인식은 구글 서버를 쓰므로 인터넷 연결이 필요합니다.

## 두 가지 모드

| | 기본 모드 (API 키 없음) | AI 면접관 모드 (Gemini 무료 키 또는 Claude 키) |
|---|---|---|
| 질문 | 분야별 질문 은행에서 출제 | 답변을 듣고 **꼬리질문** 또는 새 질문을 즉석 생성, 자기소개서 기반 맞춤 질문 |
| 내용 채점 | 분량·구조 표현·수치 사용 여부 등 겉모양만 간이 채점 | 질문 적합성·논리·구체성·직무 적합성을 실제로 읽고 채점 |
| 전달력 채점 | 말 속도, 군말(음/어), 습관어, 긴 끊김, 첫 마디까지 시간 | 같은 지표를 근거로 채점 |
| 피드백 | 규칙 기반 조언 + 답변 구성 팁 | 내 문장을 짚는 피드백 + **개선 답변 예시** + 면접 총평·연습 계획 |

### AI 면접관 연결

- **Google Gemini (무료)**: <https://aistudio.google.com/apikey> 에서 구글 계정으로 키(`AIza...`)를 무료로 발급받아
  설정 5번 "AI 면접관 연결"에 넣고 **연결 확인**을 누르세요. 키가 맞으면 쓸 수 있는 모델 목록이 채워집니다.
  기본 모델은 `gemini-3.8-flash`이고, 모델이 없으면 `gemini-3.5-flash-lite` → `gemini-3.6-flash` → `gemini-2.5-flash` 순으로 자동 전환합니다.
  무료 등급은 분당/일일 요청 수 제한이 있어서, 한도에 걸리면 잠시 기다렸다가 한 번 더 시도하고 그래도 안 되면 그 답변만 간이 채점으로 넘어갑니다.
- **Claude**: <https://console.anthropic.com> 에서 키(`sk-ant-...`)를 발급받아 넣으면 됩니다(유료).

키는 브라우저 안에만 있고 해당 AI 회사의 API로만 전송됩니다. ("이 브라우저에 키 저장"을 켜지 않으면 새로고침 시 사라집니다.)
AI 모드는 질문 1개당 API 호출 1번, 면접 끝에 총평 1번을 사용합니다.

## 설정 항목

- **지원 분야**: 일반 기업, IT/개발, 공무원/공기업, 아나운서/방송, 영업/서비스, 대학 입시
- **면접 유형**: 종합 / 인성 / 직무 / 압박
- **면접관 성격**: 다정해요 / 보통이에요 / 깐깐해요(꼬리질문 많음, 말랑이가 안경을 씁니다)
- **질문 수**, **답변 제한 시간** (시간이 다 되면 자동으로 답변 종료)
- **피드백 시점**: 답변마다 바로 보기(연습) / 끝나고 몰아서(실전)
- **답변 입력 방식**: 음성 / 타이핑(전달력 채점 제외)
- 질문 소리로 읽어주기, 질문을 다 읽으면 바로 녹음 시작

## 화면

- 듀오링고처럼 둥글고 통통한 버튼과 진행 막대, 답변마다 아래에서 올라오는 피드백 시트(점수에 따라 초록/주황/빨강)
- 말랑이는 질문을 읽을 땐 입을 움직이고, 답변 중엔 목소리 크기에 맞춰 말랑하게 늘어나고, 채점 중엔 고민하고, 점수가 좋으면 폴짝 뜁니다
- 🔥 연속 연습 일수와 ⭐ 최고 점수, 70점 이상이면 결과 화면에 꽃가루
- 라이트/다크 모드 자동 지원

## 측정하는 말하기 지표

| 지표 | 기준 |
|---|---|
| 말 속도 | 분당 250~340음절이면 적절 |
| 군말 | "음, 어, 아, 에" 등 단독 간투사. 분당 1회 이하 권장 |
| 습관어 | "약간, 뭔가, 그냥, 막, 이제, 좀" 등 반복 사용 |
| 긴 끊김 | 2.5초 이상 말이 없던 구간 |
| 첫 마디까지 | 답변 시작 후 첫 발화까지 걸린 시간 (5초 넘으면 감점) |

크롬 음성 인식은 "음/어" 같은 군말을 일부 지우고 받아쓰기 때문에, 군말 횟수는 실제보다 적게 잡힐 수 있습니다.

## 파일 구성

```
index.html        화면
style.css         스타일 (라이트/다크 자동)
js/mascot.js      말랑이 마스코트(SVG)와 표정 상태
js/questions.js   분야별 질문 은행
js/metrics.js     말하기 지표 계산 + 간이 채점
js/speech.js      음성 인식, 질문 읽어주기(TTS), 마이크 음량
js/ai.js          Gemini/Claude API 연동 (답변 평가 + 다음 질문 + 총평)
js/app.js         화면 흐름
tests/            지표 계산·AI 응답 처리 단위 테스트 (npm test)
```

결과는 화면에서 `.txt`로 저장하거나 인쇄(PDF)할 수 있고, 점수 기록은 브라우저에 최근 30회까지 남습니다.
