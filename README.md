# 말랑 면접 — AI 면접 훈련기

말로 답하면 면접관 마스코트 **말랑이**가 듣고, 꼬리질문을 던지고, **초파리 뇌 모델**로 인식·채점해 주는 면접 연습 프로그램입니다.
설치 없이 브라우저(크롬/엣지)에서 바로 돌아가며, 무료 Gemini API 키만 있으면 AI 면접관까지 쓸 수 있습니다.

## 실행 방법

### 윈도우: exe 더블클릭 (제일 쉬움)

1. `말랑면접.exe`를 더블클릭합니다.
2. 처음 한 번은 "Windows의 PC 보호" 파란 창이 뜰 수 있어요(서명 안 된 개인 프로그램이라서).
   **추가 정보 → 실행**을 누르면 됩니다.
3. 검은 안내 창과 함께 면접 창이 열립니다. 마이크 권한을 물어보면 **허용**.
4. 다 했으면 면접 창만 닫으세요. 검은 창은 잠시 뒤 저절로 꺼집니다.

- 크롬이 있으면 크롬으로, 없으면 엣지로 열립니다(둘 다 음성 인식 지원).
- 인터넷 연결이 필요합니다(음성 인식·AI 채점).
- 연습 기록과 저장한 키는 이 컴퓨터의 브라우저에 남습니다.
- exe 만들기: `./build-exe.sh` (Go 필요) → `dist/말랑면접.exe`

### 그 외: 브라우저로 직접

```bash
# 이 폴더에서
python3 -m http.server 8000      # 또는: npm start
```

그다음 크롬에서 <http://localhost:8000> 을 엽니다.
(`index.html`을 더블클릭해서 열어도 동작하지만, 그러면 마이크 권한을 매번 물어봅니다.)

> 음성 인식은 **크롬 또는 엣지**에서만 됩니다. 사파리/파이어폭스에서는 타이핑 모드로만 진행됩니다.
> 크롬 음성 인식은 구글 서버를 쓰므로 인터넷 연결이 필요합니다.

## 🪰 초파리 뇌 엔진 (인식·평가)

답변 채점은 초파리의 학습 기관인 **버섯체(mushroom body)** 회로를 본뜬 모델이 합니다.

```
 답변(음성 인식 글 + 말하기 지표)
        │
 투사뉴런 50개   말 속도·군말·결론 먼저·숫자·경험·상투어 등 21가지 특징(켜짐/꺼짐 한 쌍씩) + 글자 냄새 8채널
        │  케년세포마다 무작위 7개 연결 (실제 초파리와 같은 배선 방식, 고정된 씨앗으로 늘 같은 배선)
 케년세포 2,000개
        │  APL 뉴런 억제: 가장 센 5%(100개)만 발화 → 답변마다 고유한 '냄새 지문'
 출력뉴런(MBON)  평가 항목 5개마다 '좋음·나쁨' 한 쌍 → 둘의 힘의 비율이 점수
        ▲
 도파민뉴런(DAN) 선생님 점수가 오면 켜진 연결만 고친다 (AI 선생님 채점·사용자 피드백)
```

- **평가**: 질문 적합성·논리·구체성·직무 적합성·전달력을 0~10점으로 매깁니다. 화면의 점수는 초파리 뇌가 낸 점수입니다.
- **인식**: 답변 유형(경험(STAR)형·결론·근거형·추상·다짐형·나열형·단답형)을 알아보고,
  단어 냄새만 맡는 두 번째 회로(FlyHash)로 **예전에 했던 답을 또 하는지** 찾아냅니다.
- **타고난 지식**: 점수를 매겨 둔 예시 답변 36개(× 말하기 습관 3가지)로 미리 배워 둡니다 (`js/flycorpus.js`).
- **계속 배움**: Gemini/Claude를 연결하면 AI가 '선생님'이 되어 매 답변 채점을 보여 주고, 초파리 뇌가 그걸 보고 배웁니다.
  키가 없어도 "더 낮게 / 딱 맞아요 / 더 높게" 버튼으로 직접 가르칠 수 있습니다. 배운 뇌는 브라우저에 저장됩니다.
- **화면**: 답변마다 입력 → 케년세포 2,000개(켜진 100개 강조, 실제 배선 일부) → 출력뉴런 그림을 보여 줍니다.

**성능 (처음 보는 답변으로 검사, 예시 36개를 하나씩 빼고 나머지로 학습)**

| 항목 | 초파리 뇌 평균 오차 (10점 만점) | 평균값만 찍을 때 |
|---|---|---|
| 질문 적합성 | 0.98 | 2.66 |
| 논리·구조 | 1.10 | 2.80 |
| 구체성 | 1.33 | 3.29 |
| 직무 적합성 | 0.95 | 2.40 |
| 전달력 | 0.56 | 2.44 |

내용 점수와 정답의 상관계수 0.94, 답변 유형 인식 정확도 50%(5가지 중, 우연이면 20%).

**참고 문헌**

- Aso et al. (2014). The neuronal architecture of the mushroom body provides a logic for associative learning. *eLife* 3:e04577 — 출력뉴런·도파민뉴런 구조
- Hige et al. (2015). Heterosynaptic plasticity underlies aversive olfactory learning in *Drosophila*. *Neuron* 88:985 — 도파민에 의한 케년세포→출력뉴런 시냅스 변화
- Shen, Dasgupta & Navlakha (2023). Reducing catastrophic forgetting with associative learning: a lesson from fruit flies. *Neural Computation* 35:1797 — 초파리식 연속 학습

> 실제 초파리 뇌를 시뮬레이션한 것이 아니라, 초파리 버섯체의 구조(배선 비율·희소 발화·도파민 학습)를 그대로 따른 **계산 모델**입니다.

## 두 가지 모드

두 모드 모두 **점수는 초파리 뇌**가 매기고, 아래는 그 밖의 차이입니다.

| | 기본 모드 (API 키 없음) | AI 선생님 모드 (Gemini 무료 키 또는 Claude 키) |
|---|---|---|
| 질문 | 분야별 질문 은행에서 출제 | 답변을 듣고 **꼬리질문** 또는 새 질문을 즉석 생성, 자기소개서 기반 맞춤 질문 |
| 초파리 뇌 학습 | 내가 "더 낮게/딱 맞아요/더 높게"로 가르침 | AI 선생님 채점을 보고 매 답변 배움 |
| 피드백 | 규칙 기반 조언 + 답변 구성 팁 | 내 문장을 짚는 피드백 + **개선 답변 예시** + 면접 총평·연습 계획 |

### AI 면접관 연결

- **Google Gemini (무료)**: <https://aistudio.google.com/apikey> 에서 구글 계정으로 키(`AIza...`)를 무료로 발급받아
  설정 5번 "AI 면접관 연결"에 넣고 **연결 확인**을 누르세요. 키가 맞으면 쓸 수 있는 모델 목록이 채워집니다.
  키는 예전 형식(`AIza...`)과 새 형식(`AQ.`로 시작) 모두 됩니다.
  기본 모델은 가장 빠른 `gemini-3.5-flash-lite`(실측 2초 안팎)이고, 생각(thinking)은 최소 단계로 둡니다.
  혼잡(503)·무료 한도(429)·9초 넘게 지연되면 `gemini-3.8-flash` → `gemini-3.5-flash` → `gemini-3.6-flash` 순으로 바꾸고,
  실패한 모델은 2분 동안 뒤로 미룹니다. AI 선생님은 **최대 15초**(총평은 20초)까지만 기다리고, 넘으면 기본 피드백으로 진행합니다.
- **Claude**: <https://console.anthropic.com> 에서 키(`sk-ant-...`)를 발급받아 넣으면 됩니다(유료).

**속도**: 점수는 초파리 뇌가 내 컴퓨터에서 바로 계산하므로 제출 후 **1초 안에** 나옵니다.
AI 선생님 피드백은 뒤에서 따로 받아 도착하면 메모에 채워 넣습니다(실측 1.5~4초).

| 단계 | 실측 시간 (무료 Gemini 키) |
|---|---|
| 점수 표시 (초파리 뇌) | 0.1~0.4초 |
| AI 선생님 피드백 도착 | 1.5~3.7초 |
| 다음 질문으로 넘어가기 | 0.1초 |
| 성적표 / AI 총평 | 바로 / 2.4초 |

키는 브라우저 안에만 있고 해당 AI 회사의 API로만 전송됩니다. ("이 브라우저에 키 저장"을 켜지 않으면 새로고침 시 사라집니다.)
AI 모드는 질문 1개당 API 호출 1번, 면접 끝에 총평 1번을 사용합니다.

## 설정 항목

- **지원 분야**: 일반 기업, IT/개발, 공무원/공기업, 아나운서/방송, 영업/서비스, 대학 입시
- **면접 유형**: 종합 / 인성 / 직무 / 압박
- **면접관 성격**: 다정해요 / 보통이에요 / 깐깐해요(꼬리질문 많음, 말랑이가 안경을 씁니다)
- **질문 수**, **답변 제한 시간** (시간이 다 되면 자동으로 답변 종료)
- **피드백 시점**: 답변마다 바로 보기(연습) / 끝나고 몰아서(실전)
- **답변 입력 방식**: 음성 / 타이핑(전달력 채점 제외)
- 질문 소리로 읽어주기, 질문을 다 읽으면 바로 녹음 시작

## 화면 콘셉트: 떡집

- 면접관 **말랑이**는 넥타이를 맨 찹쌀떡. 질문을 읽을 땐 입을 움직이고, 답변 중엔 목소리 크기에 맞춰 말랑하게 눌리고, 채점 중엔 고민하고, 점수가 좋으면 폴짝 뜁니다(깐깐한 면접관이면 안경을 씁니다)
- 오트 크림 바탕에 딸기·쑥·단호박·블루베리 색, 누르면 젤리처럼 눌렸다 튕기는 버튼
- 진행 상황은 **꼬치떡**: 질문 하나가 떡 하나이고, 답하면 점수에 따라 쑥(좋음)·단호박(보통)·팥(보완) 색으로 물듭니다
- 답변은 줄 노트에 받아 적고, 녹음 중엔 REC 표시
- 답변마다 마스킹테이프 붙은 **면접관 메모**와 점수 도장, 끝나면 **면접 성적표**에 등급 도장이 쾅
- 이번 주 연습 **도장판**(월~일, "참 잘했어요" 도장)과 최고 기록
- 라이트/다크 모드 자동 지원

## 측정하는 말하기 지표

| 지표 | 기준 |
|---|---|
| 말 속도 | 분당 250~340음절이면 적절 |
| 군말 | "음, 어, 아, 에" 등 단독 간투사. 분당 1회 이하 권장 |
| 습관어 | "약간, 뭔가, 그냥, 막, 이제, 좀" 등 반복 사용 |
| 긴 끊김 | 2.5초 이상 말이 없던 구간 |
| 첫 마디까지 | 답변 시작 후 첫 발화까지 걸린 시간 (5초 넘으면 감점) |

크롬 음성 인식은 "음/어" 같은 군말을 일부 지우고 받아쓰기 때문에, 군말 횟수는 실제보다 적게 잡힐 수 있습니다.

## 파일 구성

```
index.html        화면
style.css         스타일 (라이트/다크 자동)
js/mascot.js      말랑이 마스코트(SVG)와 표정 상태
js/questions.js   분야별 질문 은행
js/metrics.js     말하기 지표 계산 + 기본 피드백 문장
js/speech.js      음성 인식, 질문 읽어주기(TTS), 마이크 음량
js/ai.js          Gemini/Claude API 연동 (AI 선생님: 피드백 + 다음 질문 + 총평)
js/flybrain.js    🪰 초파리 뇌 엔진 (투사뉴런→케년세포→출력뉴런, 도파민 학습, FlyHash 기억)
js/flycorpus.js   초파리 뇌의 타고난 지식(점수 매긴 예시 답변 36개)
js/flyview.js     초파리 뇌 활성 그림
js/app.js         화면 흐름
launcher.go       윈도우 exe 실행기 (화면 파일을 품고 앱 창으로 열기)
winres/           exe 아이콘·버전 정보
build-exe.sh      exe 빌드 스크립트
tests/            지표 계산·AI 응답 처리 단위 테스트 (npm test)
```

결과는 화면에서 `.txt`로 저장하거나 인쇄(PDF)할 수 있고, 점수 기록은 브라우저에 최근 30회까지 남습니다.
