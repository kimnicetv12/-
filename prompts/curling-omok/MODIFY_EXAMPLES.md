# ✏️ 만든 뒤 Claude Code로 수정하는 법

`PROMPT.md`로 게임을 만들면 Unity 프로젝트 루트에 `CLAUDE.md`, `docs/`, `.claude/commands/`가 생깁니다.
Claude Code는 실행될 때마다 `CLAUDE.md`를 자동으로 읽기 때문에, **그 폴더에서 Claude Code를 켜고 원하는 걸 말하기만 하면** 구조를 알고 수정합니다.

## 1. 바로 쓰는 슬래시 명령 (프롬프트가 만들어 둠)

| 명령 | 예시 |
| --- | --- |
| `/add-board` | `/add-board 용암 화산 — 가장자리에 용암 구역(닿으면 돌 제거), 중앙에 회전 범퍼 1개` |
| `/add-skin` | `/add-skin 트레일 "번개" 전설 등급 1500골드` |
| `/tune-ai` | `/tune-ai 보통 난이도가 너무 어려움, 실수 확률을 15%로` |
| `/balance-gold` | `/balance-gold 5줄 승리 보상을 지금보다 30% 늘려줘` |
| `/add-language` | `/add-language 중국어 간체` |
| `/run-tests` | `/run-tests` (테스트 돌리고 실패하면 고침) |

## 2. 일반 수정 요청 예시 (그냥 말로)

- "돌이 너무 빨리 멈춰. 클래식 보드 마찰을 20% 줄여줘."
- "줄 판정이 너무 관대해. 각도 허용치를 12도로 줄이고 테스트도 고쳐줘."
- "3줄 모드에서 AI가 방어를 너무 잘해. 3줄 방어 가중치를 낮춰줘."
- "결과 화면에 연승 보너스를 추가해줘. 3연승부터 +10%."
- "스킨 화면에 '랜덤 뽑기' 버튼을 만들어줘. 500골드, 중복이면 골드 일부 환급."
- "일일 출석 보상 기능 추가해줘."
- "실제 AdMob SDK로 MockAdService를 교체해줘." (SDK 패키지는 직접 설치 후 요청)

## 3. 수정 요청을 잘하는 팁

1. **한 번에 하나씩** 요청하고, 끝나면 Unity에서 확인 → 커밋.
2. 수치 변경은 "얼마나"를 숫자로 (예: "조금" 대신 "20%").
3. 버그는 **재현 방법 + 콘솔 에러 복사**를 같이 붙여넣기.
4. 큰 기능은 먼저 "계획만 세워줘"라고 한 뒤 승인하고 진행 (Claude Code의 Plan 모드: `Shift+Tab`).
5. 기획이 바뀌면 "`docs/GAME_DESIGN.md`도 같이 갱신해줘"라고 덧붙이기 (프롬프트에 이미 규칙으로 들어가 있지만 확인용).
