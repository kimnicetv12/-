# Special Stage — 태블릿용 3D 랠리 시뮬레이터

실제 WRC 스테이지의 도로와 지형 위에서, 시뮬레이터식 차량 물리로 달리는 브라우저 게임입니다.
설치 없이 태블릿 브라우저(iPad Safari, Android Chrome)에서 바로 실행되며 터치·기울기·게임패드·키보드를 지원합니다.

## 스테이지 (실제 도로)

| 스테이지 | 랠리 | 노면 | 거리 | 데이터 |
| --- | --- | --- | --- | --- |
| 콜 드 튀리니 (La Bollène-Vésubie → Col de Turini) | Rallye Monte-Carlo | 아스팔트 + 살얼음 | 11.90 km, 687 → 1607 m | 도로 M70 전 구간 |
| 우닌포흐야 (Ouninpohjantie, Jämsä) | Rally Finland | 고속 자갈 | 17.45 km | Ouninpohjantie 전 구간 |
| 바르고센 (Colin's Crest, Värmland) | Rally Sweden | 눈 · 스터드 타이어 | 6.20 km | 콜린스 크레스트를 지나는 숲길 |

- **도로 선형**: OpenStreetMap의 실제 도로를 따라 경로를 찾고 2 m 간격으로 재샘플링했습니다.
- **고도·지형**: AWS Terrain Tiles(EU-DEM/SRTM 기반, 약 25–30 m 해상도)를 사용합니다. 도로 높이는 DEM을 도로를 따라 평활화하고 실제 도로처럼 최대 경사(11–12 %)를 넘지 않도록 맞췄습니다.
- **호수·숲·건물**: OpenStreetMap 폴리곤을 그대로 배치합니다. 나무 하나하나와 관중 위치는 절차적으로 생성합니다.
- **보강한 부분**: 콜린스 크레스트 점프는 DEM 해상도로는 드러나지 않아 실제 위치에 도약대 형상을 덧입혔습니다. 튀리니의 살얼음 구간 위치는 게임용으로 정한 것입니다.
- **목표 시간**은 Rally2 차량의 노면별 평균 속도로 계산한 추정치이며 공식 기록이 아닙니다.

## 실행

### 바로 플레이
claude.ai에 게시된 플레이 링크를 태블릿에서 열면 됩니다(PR 설명에 링크가 있습니다).

### 직접 띄우기 (같은 Wi‑Fi의 태블릿에서)
```bash
cd rally
python3 -m http.server 8080
# 태블릿 브라우저에서 http://<이 컴퓨터의 IP>:8080 열기
```
ES 모듈과 `fetch`를 쓰기 때문에 `index.html`을 파일로 직접 열면 동작하지 않습니다. 정적 파일 서버(GitHub Pages 포함)면 어디든 됩니다.

> 기울기 조향은 iOS에서 HTTPS 페이지에서만 센서 권한을 받을 수 있습니다. HTTP로 띄웠거나 센서를 쓸 수 없으면 자동으로 슬라이드 조향으로 바뀝니다.

## 조작

| | 터치 (가로 화면) | 게임패드 | 키보드 |
| --- | --- | --- | --- |
| 조향 | 왼쪽 화면을 누른 채 좌우로 밀기 / 기울기 / 좌우 버튼 | 왼쪽 스틱 | ← → / A D |
| 가속 · 브레이크 | 오른쪽 페달 — 누르는 높이만큼 깊게 밟힘 | RT · LT | ↑ ↓ / W S |
| 핸드브레이크 | 원형 버튼 | A (또는 X) | Space |
| 변속 (수동일 때) | ▲ ▼ 버튼 | RB · LB | E · Q |
| 카메라 · 복귀 · 일시정지 | 오른쪽 위 버튼 | Y · Back · Start | C · R · Esc |

카메라 버튼은 추격 → 원거리 → 콕핏 → 보닛 → 범퍼 순서로 바뀌고, 마지막으로 고른 카메라를 기억합니다. 콕핏에서는 핸들이 실제 조향만큼 돌고, 대시 디스플레이에 회전수·기어·속도가 나오며, 핸드브레이크 레버와 시퀀셜 레버가 조작에 맞춰 움직입니다.

자동 변속일 때 정지 상태에서 브레이크를 계속 누르면 후진 기어가 들어갑니다.

## 물리 모델

- **섀시**: 6자유도 강체, 1/360초 고정 스텝. 요·피치·롤 관성, 공기저항과 다운포스.
- **서스펜션**: 바퀴별 레이캐스트, 스프링·범프/리바운드 댐퍼(고속 니 포함)·안티롤바·점진형 범프스톱. 차체가 바닥에 닿거나 전복되면 차체 접촉으로 처리합니다.
- **타이어**: 노면별(아스팔트·빙판·자갈·느슨한 자갈·압설·깊은 눈·풀·흙) 최대 마찰계수, 최대 슬립률/슬립각, 미끄러질 때 남는 마찰, 하중 민감도, 결합 슬립(마찰원), 완화 길이(relaxation length)로 계산하는 과도 응답.
- **구동계**: 1.6 터보 토크 곡선, 터보 부스트와 안티랙, 레브 리미터, 오토 클러치, 5단 시퀀셜, Rally2 구조(센터 디퍼렌셜 없이 앞뒤 직결 + 앞뒤 LSD). 엔진·클러치·디퍼렌셜·브레이크를 하나의 구속 조건계로 풀어 휠스핀·잠김·엔진 브레이크가 자연스럽게 나옵니다. 핸드브레이크는 실제 차량처럼 클러치와 후륜 연결을 끊습니다.
- **충돌**: 나무 줄기, 튀리니의 돌 난간, 건물 벽, 아치 기둥과 충돌 임펄스로 부딪힙니다.

헤드리스 테스트에서 측정한 값: 0→100 km/h 아스팔트 4.1–4.4 초 / 자갈 4.6 초 / 눈 5.7 초, 100→0 제동 아스팔트 약 43 m / 자갈 51 m / 눈 72 m, 최대 횡가속도 아스팔트 약 1.07 g, 콜린스 크레스트 137 km/h 진입 시 약 36 m 비행.

## 그래픽

- **조명**: 하늘(그라데이션·태양·절차적 구름)로 만든 이미지 기반 조명, 그림자를 드리우는 태양, 태양 방향으로 붉어지고 골짜기에서 짙어지는 대기 안개.
- **재질**: PBR. 지형은 월드 좌표 디테일·노멀 맵과 경사면 트라이플래너 암석, 도로는 노면별 노멀·거칠기 맵(타맥의 고무 자국, 눈길의 반들반들한 바퀴 자국), 클리어코트 차량 도장, 하늘을 비추는 유리·물·빙판.
- **식생**: 가까운 나무는 고해상도 모델, 먼 나무는 저해상도 모델로 바꾸고, 바람에 흔들리는 풀·도로변 바위·나무 아래 접지 그림자를 그립니다.
- **후처리**: HDR 블룸, 색 보정, 비네트, 속도에 따른 방사형 모션 블러, FXAA/SMAA, 태양 렌즈 플레어.

| 품질 | 대상 | 화면 삼각형 (측정) |
| --- | --- | --- |
| 절전 | 오래된 태블릿 | 약 26만 |
| 균형 (태블릿 기본) | 대부분의 태블릿 | 약 47만 |
| 고품질 | 최신 iPad / 고성능 안드로이드 | 약 87만 + 나무 그림자 |
| 울트라 | M 시리즈 iPad / PC | 약 124만, 4K 그림자 |

프레임이 떨어지면 해상도를 자동으로 낮춥니다. 브라우저의 WebGL로 그리기 때문에 언리얼 엔진 5의 루멘·나나이트 같은 기능을 그대로 쓸 수는 없고, 그 범위 안에서 태블릿이 감당할 수 있는 만큼 끌어올렸습니다.

## 개발

```bash
cd rally
npm install        # 테스트용 three, delaunator (게임 자체는 CDN의 three를 씁니다)
npm test           # 물리·카메라 테스트 + 세 스테이지를 로봇 드라이버가 완주하는 통합 테스트
python3 tools/bake_stage.py           # OSM·DEM에서 스테이지 JSON 다시 만들기 (numpy, Pillow 필요)
python3 tools/bake_stage.py turini    # 한 스테이지만
```

| 경로 | 내용 |
| --- | --- |
| `tools/bake_stage.py` | OSM 도로 경로 탐색, DEM 샘플링, 경사 제한, 폴리곤 추출, 압축 JSON 생성 |
| `stages/*.json` | 구워진 스테이지 데이터 (도로·높이 격자는 delta + zlib 압축) |
| `src/physics/` | 차량 동역학, 노면 마찰 특성, 장애물 충돌 |
| `src/world/` | 스테이지 디코딩, 도로 모델, 지형 삼각망(Delaunay), 도로변 배치 |
| `src/game/` | 주행 세션(계시·스플릿·페널티·복귀), 페이스노트 생성과 코드라이버, 로봇 드라이버 |
| `src/render/` | three.js 지형·도로·나무·풀·건물·하늘, 셰이더 패치, 후처리, 차량 모델과 콕핏, 입자, 카메라 |
| `src/input/`, `src/audio/`, `src/ui/` | 터치/기울기/패드/키보드, WebAudio 엔진음, HUD·메뉴·설정 |
